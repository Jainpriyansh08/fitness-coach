# Exercise library (coach-vetted)

Exercises and demo videos the coach has already used in client plans. Prefer these, so clients
see familiar, checked demos. Settings: **H** home (bodyweight/household items), **D** home with
dumbbells/bands, **G** gym, **P** park/terrace. Adapt cues and loads to the client (e.g. "5 kg"
only if that's their equipment).

Video rules: links below were chosen by the coach. Before sending a plan, spot-check that links
still open. For a new exercise, find a demo via web search and use only a URL you have actually
seen; if none is verified, leave `video` empty — the builder adds a labelled YouTube search link.
When the coach approves a new video, add it here (Claude Code) so it's reused next time.
